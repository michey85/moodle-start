---
title: 3.3. Варианты активностей курса
---

Из коробки Moodle предлагает 7 типов ресурсов и 15 элементов для создания курса. Причем некоторые элементы внутри также содержат вариации. Дополнительно данный набор можно расширять при помощи плагинов.

Чтобы начать работу над активностями курса, необходимо создать курс типа “Разделы по темам” или “Разделы по неделям”, войти в режим редактирования, передвинув ползунок в правом верхнем углу и для выбранного шага курса нажать на кнопку “Добавить элемент или ресурс” (Примечание: в зависимости от темы Moodle положение и внешний вид элементов может отличаться).

![[Pasted image 20260816145145.png|Режим редактирования Moodle 300]]

![[Pasted image 20260816145152.png|Добавление элемента Moodle 500]]

В открывающемся диалоге в начале идет поиск по ресурсам, а дальше сам набор, для удобства разбитый на три вкладки: “Все”, “Элементы курса”, “Ресурсы”.

![[Pasted image 20260816145312.png|Поиск и добавление элемента Moodle 450]]

Обратите внимание, что для каждого элемента доступна иконка с буквой i, по клику на которую можно получить информацию о самом ресурсе.

## Элемент “Анкета”

Первый элемент из списка предлагает готовые наборы опросов. Активность имеет немного настроек. Необходимо выбрать один из стандартизированных вариантов анкеты (их описание можно почитать, кликнув на иконку с вопросительным знаком), и в результате будет автоматически сформирован опросник с предустановленными вариантами ответов.

![[Pasted image 20260816145328.png|Добавление опроса Moodle 300]]

Например, выбор “ATTLS (20 вопросная версия)” создаст те самые 20 вопросов и будет выглядеть следующим образом:

![[Pasted image 20260816145335.png|Пример опроса Moodle 500]]

## Элемент “Вики”

Данный ресурс может быть как индивидуальным для каждого студента - что-то вроде личного блокнота, но чаще это коллективное пространство - база знаний. Эдакая персональная “Википедия” на уровне курса.

Работает она не слишком очевидно на первый взгляд. При добавлении ресурса нужно задать его название, а также название первой страницы Вики. Причем изменить это название впоследствии нельзя. Сами Вики-страницы могут быть в одном из трех форматов: HTML, Creole и NWiki (если не знакомы с этими понятиями используйте, просто используйте HTML). При создании ресурса выбирается формат по умолчанию, но в дальнейшем при создании страниц пользователи вольны выбирать один из этих форматов (если не установлен чекбок “Принудительный формат”).

После создания элемента необходимо создать первую страницу. Она уже имеет название, заданное на предыдущем шаге. 

![[Pasted image 20260816145345.png|Добавление вики-страницы Moodle 500]]

Главная страница может содержать любой текст, но обычно содержит ссылки на другие страницы. Сами страницы создаются путем заключения их названий в двойные квадратные скобки, например, `[[Полезные YouTube каналы по Moodle]]`. Сам факт добавления названия подобным образом создает пустую страницу, которую в дальнейшем надо будет наполнить. 

После сохранения главной страницы, на ней появится активная ссылка с введенным текстом внутри двойных квадратных скобок. При клике на нее будет предложено создать контент для этой новой страницы. В свою очередь вложенные страницы также могут содержать текст в двойных квадратных скобок, создавая таким образом дополнительные страницы.

При просмотре Вики страниц доступен выпадающий список с вариантами оформления. Он позволяет переключиться на комментарии, если они включены, посмотреть историю редактирования страниц, а опция “Карта” выведет список существующих Вики-страниц.

![[Pasted image 20260816145400.png|Список Вики-страниц Moodle 150]]

## Элемент “Глоссарий”

Глоссарий - это словарь терминов, использующийся на конкретном курсе или сайте в целом. Данный вид активности - коллективный, и подразумевает, что любой слушатель может пополнить или отредактировать набор терминов.

Для преподавателей доступна опция модерации правок, вносимых пользователями. Также есть гибкие настройки возможности редактирования и комментариев.

Если в настройках “Записи” - “Автоматическое связывание записей глоссария” отмечено как “Да”, то во всем курсе вхождение заданных строк превратится в ссылки с автоматическими подсказками. Для этого в момент добавления слова в словарь дополнительно надо отметить чекбокс “Эта запись должна автоматически связываться” в разделе “Автосвязывание”. При этом в графе “Ключевые слова”, при добавлении термина, можно указать разные вариации, для которых также будет работать автоматическая подсказка по курсу.

Дополнительно для включения автосвязывания на уровне курса необходимо перейти через меню “Ещё” - “Фильтры” и выбрать опцию “Включен” для фильтра “Автоматическое распознавание ссылок на элементы курса”. После чего сохраниться. Убедитесь также, что на уровне сайта эта возможность также активна. Для этого идем в “Администрирование” - “Плагины” - “Фильтры” - “Управление фильтрами” и проверяем, что пункт “Автоматическое создание ссылок на записи модуля «Глоссарий»” имеет значение “Включен”.

В дальнейшем фильтрами можно управлять на уровне каждого элемента курса, и если в тестовом задании не надо показывать подсказку на слова из глоссария, то эту возможность следует отключить.

На странице глоссария есть кнопка добавления новых терминов, поиск по уже существующим и варианты сортировки.

При наличии глоссария, на курсе можно добавить в боковую панель специальный блок “Случайная запись из глоссария”.

## Элемент “Задание”

Активность предназначена для того, чтобы студенты могли загрузить свою работу на проверку. Ответом может быть просто текст, либо же загруженный файл. Само описание задания заполняется как обычный “Текст и медиа”, то есть нам доступны любые медийные элементы, а также гиперссылки. При необходимости к заданию можно загрузить рабочие файлы как вложения.

Преподаватель решает в каком формате должен быть ответ на задание. Если это файл, то необходимо задать максимальное количество загружаемых файлов, их лимит по размеру и допустимые типы файлов (например, только архив или изображение).

![[Pasted image 20260816145530.png|Ответ в виде текста Moodle 500]]

При выборе опции “Ответ в виде текста” преподаватель может задать максимальное количество слов для ответа.

Обратная связь от преподавателя также настраивается. В том числе есть возможность встроенных комментариев, которые имитируют заметки на бумажном носителе (подходит не для всех типов загружаемых файлов).

![[Pasted image 20260816145535.png|Типы отзывов Moodle 500]]

Сами задания могут быть анонимными, если в разделе “Оценка” выбрать “Оценивание вслепую”, а опция “Использовать поэтапное оценивание” может быть полезно, когда над курсом работают несколько преподавателей.

## Элемент “Книга”

Данный вариант хорош не только для публикации книги, как таковой, но и для инструкций по работе с курсами. В частности портал Moodle Academy использует его для своих курсов в качестве вводного элемента для каждого курса, где пошагово знакомит с содержимым курса, его пререквизитом, правилами прохождения и итоговым результатом.

При работе с книгой у студентов есть возможность открыть оглавление в правой боковой области (обычно свернутой по умолчанию), и переключаться между главами по кнопкам навигации.

Данный элемент может подойти также в качестве набора последовательных страниц с обучающим материалом, включающим не только текст и иллюстрации, но и видео материалы.

## Элемент “Обратная связь”

В отличие от “Анкеты” блок обратной связи позволяет самостоятельно создать вопросы для обратной связи и выбрать варианты как именно студентам будет предложено поделиться впечатлениями. По умолчанию опросы анонимные, но это можно изменить в разделе настроек “Параметры вопросов и ответов”.

После создания самого элемента (в минимальном варианте достаточно ввести название) необходимо создать сами вопросы по кнопке “Редактировать вопросы”.

![[Pasted image 20260816145612.png|Типы вопросов Moodle 500]]

Среди доступных вариантов типов вопросов есть как опросник в виде теста (“Множественный выбор”), так и текст в свободной форме (“Короткий ответ” или “Эссе”).

![[Pasted image 20260816145617.png|Типы вопросов Moodle 300]]

## Элемент “Опрос”

Предназначен для сбора мнений по тому или иному вопросу. Требует задать тему и варианты ответов. При этом статистика по умолчанию доступна только учителю курсу, но есть возможность гибко настроить видимость и для студентов - графа “Результаты”, опция “Публикация результатов опроса”.

![[Pasted image 20260816145632.png|Опрос Moodle 300]]

Среди прочих настроек - возможность изменить мнение после голосования или выбрать несколько вариантов, возможность ограничить число возможных выборов каждого варианта.

![[Pasted image 20260816145644.png|Результаты опроса Moodle 600]]

После публикации опросника на странице ресурса будет доступна вкладка “Ответы”, где можно будет увидеть как голосовали слушатели курса. 

Само голосование визуально может выглядеть по-разному. В настройке “Режим отображения” предлагается две опции: “Отображать горизонтально”, “Отображать вертикально”. Первый вариант больше подойдет при небольшом варианте ответов, второй - когда вариантом больше трех.

## Элемент “Тест”

Тестирование скрывает в себе множество возможностей. Это и множественный выбор, и текстовый ответ, и верно/неверно и так далее. Всего 16 вариантов.

![[Pasted image 20260816145655.png|Тест Moodle 400]]

При этом один тестовый набор может содержать в себе проверочные задания разных типов. А сам вопрос может состоять не только из текста, но из медиа файлов.

Тест, как элемент, имеет множество настроек, таких как - проходной балл, количество попыток, метод оценивания, настройки просмотра, автоматический отзыв в зависимости от результата и так далее. Если какая-то из настроек вызывает вопросы - воспользуйтесь иконкой с вопросительным знаком.

Работая над курсом, мы можем создавать банк вопросов и затем переиспользовать его содержимое в тестах конкретных тем, а можем создавать все вопросы непосредственно в создаваемом элементе “Тест”.

![[Pasted image 20260816145706.png|Банк вопросов Moodle 300]]

За исключением типа вопроса “Эссе”, каждая попытка прохождения теста оценивается автоматически. При этом преподаватель может настроить подсказки и показ правильных ответов после завершения прохождения.

## Элемент “Форум”

Обсуждение по ходу обучения могут быть в различном формате. Количество форумов на курс не ограничено. Например, на первых шагах можно создать форум, где студенты расскажут друг другу о себе вводную информацию - своеобразное приветствие. В дальнейшем это будут тематические обсуждение материалов курсов.

При создании форума доступно пять разных типов форума. Значение по умолчанию (“Стандартный форум для общих обсуждений”) позволяет каждому участнику курса создавать темы для обсуждений.

![[Pasted image 20260816145716.png|Форум Moodle 400]]

Вариант “Простое обсуждение” позволяет преподавателю задавать тему для обсуждения, а слушателям - отвечать на нее.

Чтобы получить больше информации про разницу типов форума, кликните на иконку с вопросительным знаком рядом с выпадающим списком.

При добавлении темы для обсуждения учитель может выбрать “Расширенную форму ответа”, что позволяет закрепить тему на верхнем уровне относительно других тем форума. Закрепленная тема будет помечена специальной иконкой.

![[Pasted image 20260816145729.png|Закрепленная тема 150]]

![[Pasted image 20260816145734.png|Форум Moodle 70]]

На страница форума любой желающий может подписаться на обновления как всего форума, так и конкретных обсуждений. А сами обсуждения можно сортировать, кликая на название колонок, например, “Ответы”.

У преподавателя также есть возможность заблокировать любое обсуждение, кликнув в строке темы по иконке с тремя точками и выбрав опцию “Заблокировать это обсуждение”. Плюс на любое сообщение преподаватель может отправить личное сообщение, доступное только конкретному студенту, причем без возможности ответить на это сообщение.

## Элемент H5P

H5P - это особый продукт с открытым исходным кодом, позволяющий создавать интерактивный контент. Это могут быть презентации, видео и другие мультимедиа, вопросы, кроссворды, тесты, игры и многое другое. Элемент H5P позволяет загружать специальный контент H5P и добавлять его в курс. Сам контент можно создать на сайтах [h5p.com](https://h5p.com/) и [h5p.org](https://h5p.org/), либо добавить вручную с главной страницы курса через меню “Ещё” - “Банк контента” - кнопка “Добавить”.

![[Pasted image 20260816145747.png|H5P контент 400]]

Если на курсе в банк контента был предзагружен или вручную добавлен интерактивный элемент, то его можно будет загрузить в настройке “Файл пакета” элемента H5P.

![[Pasted image 20260816145752.png|H5P Элемент 200]]

Кроме того, H5P контент может быть также использован на любом элементе курса, где есть редактор текста и медиа. 

## Дополнительные элементы

Мы уделили время наиболее употребим элементам курсов, но их больше и каждый содержит описание и примеры полезного использования. Например, “База данных” может пригодиться для исследования и сбора информации в одном месте, “Лекция” может быть последовательностью из страниц с теорией и тестовых заданий, а “Чат” - для общения в реальном времени. Кроме того, при помощи плагинов мы можем устанавливать дополнительные наборы активностей для курса, если стандартного набора по каким-либо причинам недостаточно.
